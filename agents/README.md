# Agent Docs

Built-in agents:

- `pi -> npx --package=pi-acp -- pi-acp`
- `openclaw -> openclaw acp`
- `codex -> npx -y --package=@agentclientprotocol/codex-acp -- codex-acp`
- `claude -> npx -y --package=@agentclientprotocol/claude-agent-acp -- claude-agent-acp`
- `gemini -> gemini --acp`
- `cursor -> cursor-agent acp`
- `copilot -> copilot --acp --stdio`
- `ante -> ante acp` (experimental)
- `antigravity -> agy_acp_server.par` (`--uid=` on Linux; `.exe` on Windows)
- `deepseek-harness -> dsh --profile acp`
- `devin -> devin acp`
- `droid -> droid exec --output-format acp` (`factory-droid` and `factorydroid` also resolve to `droid`)
- `fast-agent -> uvx fast-agent-mcp acp`
- `fx -> fx acp`
- `goose -> goose acp`
- `grok-build -> grok agent stdio`
- `iflow -> iflow --experimental-acp`
- `junie -> junie --acp=true`
- `kilocode -> npx -y --package=@kilocode/cli -- kilo acp`
- `kimi -> kimi acp`
- `kiro -> kiro-cli-chat acp`
- `mcode -> mcode acp`
- `mux -> npx -y --package=mux -- mux acp` via an ACPX-owned npm range
- `octomind -> octomind acp developer:general`
- `opencode -> npx -y --package=opencode-ai -- opencode acp`
- `pool -> pool acp`
- `qoder -> qodercli --acp`
- `qwen -> qwen --acp`
- `trae -> traecli acp serve`
- `zeroclaw -> zeroclaw acp`
