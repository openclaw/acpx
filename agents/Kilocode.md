# Kilocode

- Built-in name: `kilocode`
- Default command: `npx -y @kilocode/cli acp`
- Upstream: https://kilocode.ai

## Embedded inspection

Embedded inspection resolves the installed `kilo acp` entrypoint under the canonical agent name `kilocode`. Install and configure Kilo Code before acquiring a model catalog or starting a session.

Inspection performs filesystem lookup only. See [embedded agent discovery](../docs/session-control.md#embedded-agent-discovery) for the registry contract and session lifecycle.
